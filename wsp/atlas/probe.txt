Answer: When the second train leaves, the first has travelled for 45 minutes, which is 0.75 hours, so it is 80 × 0.75 = 60 kilometres ahead. The second train closes the gap at 100 − 80 = 20 kilometres per hour. 60 ÷ 20 = 3 hours. The second train catches the first at 13:00.

def fibonacci(n):
    """Return the n-th Fibonacci number."""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a


class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if not self.items:
            raise IndexError("pop from empty stack")
        return self.items.pop()

    def __len__(self):
        return len(self.items)

function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);

Why is the sky blue? Sunlight is a mixture of all colours. As it passes through the air, the shorter blue wavelengths are scattered in every direction by the molecules of the atmosphere far more than the longer red ones.
